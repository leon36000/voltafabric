# R406 — real QKV through GDN convolution and Q/K normalization

`gdn_cpu::ConvHistory` implements a bounded CPU reference for Strata fb58's four-tap channel-major convolution, oldest-to-newest history shift, SiLU, then per-head L2 normalization of Q and K. It binds run/model/layer/epoch, checks geometry and finite values and commits its three-sample history only after the whole result is valid. It deliberately leaves Q unscaled; a later recurrence must apply the backend-specific `1/sqrt(head_dim)` exactly once. Batch/attempt identity, persistence, replay prevention and ownership remain the caller's responsibility. The arithmetic derives from the MIT donor `gdn.cu` and `native_gdn_preprocess.cu`, not from a claim of bitwise CUDA equivalence.

On PC1 CPU, the actual layer-0 `ssm_conv1d.weight` span at dense offset 42726592, length 163840, had observed SHA-256 `86971b2b293c0f8d662169eac001156cb7d5d81bbb28fe75d78e358f1c39b476`, with stable descriptor metadata during observation. The diagnostic started from zero history and consumed R405's actual token-42 QKV vector SHA-256 `2967a329365c17bb10ec76211c650d6dc1502bf273abf07c75466a1443c90f64`. Its 10240-value unscaled Q/K/V result has SHA-256 `819f7a0b76b29a9a25e587c4391b85dba0075a71b75cce558284b99ce3b1def2`. An independently written NumPy implementation checked every value: maximum absolute difference `1.1920928955078125e-07`, within 1e-6.

A CPU unit test verifies oldest/newest ordering across two steps, Q/K normalization, identity/NaN/overflow refusal and no history mutation on failure. Strict Rust clippy passes. The single real-token test uses zero history, so it does not validate real recurrent continuation or GPU arithmetic. Attention gate, alpha/beta, recurrence, output normalization and projection, post-attention hyperconnection, model generation and inter-PC execution remain unqualified. No GPU, network worker, service change or UNKNOWN replay occurred.
