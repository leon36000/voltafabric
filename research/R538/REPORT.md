# R538 — sampled scalar projections on the live 92-position trace

The separately compiled scalar checker adapts `adapters/native_ggml/check_sc117_qsa_r430.cpp` to all 92 positions captured during R537's real local CPU generation. For each position it re-quantizes the observed mixed input or gated-attention input using the GGML dot trait, decodes the selected checkpoint weight rows and activation, and computes an independent scalar f64 dot. It compares those values to the observed Q, K, V and output projections using the prior R430 threshold `1e-5 + 1e-3*abs(reference)`. It checks 11 Q rows, five K rows, five V rows and seven output rows at each position: 2,576 scalar row comparisons in total.

Maximum absolute errors were 9.828733e-7 (Q), 2.221969e-7 (K), 2.586361e-7 (V), and 1.172483e-7 (output); each sampled element met its own threshold. The full-checkpoint Q0, Q1, K, V and output spans independently matched the locally pinned R430 manifest hashes, and the live trace matched R537's SHA256 before and after the check. A negative test changed the observed Q row 0 value at position 91 in memory; the checker rejected it with no successful result output. The source shard and trace descriptors were checked for identity/size/time changes during the check.

This is sampled projection coverage, not all 15,872 rows per position.
