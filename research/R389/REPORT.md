# R389 — local C++ binary client for the native coordinator

After the R388 JSON initialization and `enter_binary` negotiation, the coordinator accepts bounded `VFB1` requests and returns `VFR1` replies with little-endian FP32 input/output, batch and slot positions. The exact frame is documented in `adapters/native_ggml/NATIVE_BRIDGE.md`. Dimensions are bounded to 8 tokens and 128 total slots, matching the pinned Strata window limit. The initialization still binds run/model/plan/layer/epoch and trusted caller-provided expert digests; this binary transport does not authenticate them independently.

`adapters/strata_native_bridge/pipe_client` is a reusable C++17 client for connected POSIX AF_UNIX stream sockets, not rsockets. It uses nonblocking sockets, bounded poll deadlines and `MSG_NOSIGNAL`, checks the batch, format, shape, finite values, duplicate and missing CPU positions, and stages every row before writing the destination. External rows remain untouched. Lost or malformed replies terminalize the client and are UNKNOWN; no replay or fallback is attempted. Handshake, lifecycle, real ownership provenance, external synchronization and failure propagation remain the caller's responsibility.

A genuine local end-to-end test runs the C++ client against the Rust coordinator and two persistent rank-session subprocesses, using a sparse synthetic SC117-layout pack. Two distinct batches produce unweighted FP32 rows bit-identical to direct provider output, and an external slot stays unchanged. This path was executed with `VF_STRATA_CPP_CLIENT` pointing to the built C++ test executable, including an optimized C++/Rust run. Rust targeted tests passed in debug and release, strict feature-enabled Clippy passed, and C++ CTest passed in Debug and Release. Separate adversarial C++ tests reject duplicate positions, truncated bodies, a wrong batch and a nonfinite value with the destination unchanged. The optional integration leg is exercised only when `VF_STRATA_CPP_CLIENT` is supplied; ordinary test runs without it do not prove C++/Rust interoperability.

This client is not yet installed at Strata's actual `expert_pool_dispatch_multi` final-kind site. The existing donor callback is void and the verifier can continue GPU work after it returns; safe error propagation and draining of outstanding waits must be implemented and tested before connecting it. No live checkpoint, GPU, inter-PC execution, performance or full generation is qualified. No native formats or weighted collector contracts are conflated.
