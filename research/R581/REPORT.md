# R581 — read-only recovery audit for frozen PC1 sessions

Adds `tools/audit_pc1_session_snapshots.py` to inspect the five recovered PC1 session-record archives without restoring or creating any ledger. It checks bounded regular files, non-symlink reads, file identity during read, duplicate JSON keys and paths, session identity digest/path, full stamp/attempt/batch identity, close markers, and missing or orphan batch markers. A supplied candidate matching an observed session is marked `CONSUMED_NO_REPLAY`; an absent candidate is `NOT_OBSERVED_NOT_AUTHORIZED`. Neither case establishes a lease or authorizes a run. A done marker records only a payload hash: the archived FP16 outputs are absent and were not verified. The tool never marks the snapshot ready for live use.

On the five frozen parts, it found 4,398 records, 653 distinct session identities with correct deterministic directory hashes, 1,212 batch claims and 1,210 done markers. Two batches have a claim without done, and both sessions lack a close marker; 24 sessions overall lack a close marker and one lacks a process marker. No done marker lacks a claim and no recorded close exit code is nonzero. The tool returns exit 1 for unresolved markers. The identities of the two missing done claims are preserved in AUDIT.json, and every observed identity remains non-replayable regardless of these counts. These snapshots may be incomplete; a PID or lack of close marker here is not a current process status.

The 82 distinct archived PC1 run_id strings have zero exact string overlap with 80 effective IDs in the two recovered R53 snapshots. This narrow observation does not show that the sessions are unrelated to R53 reservations: run and namespace IDs can differ. The source snapshots remain frozen and neither they nor this audit reconcile the authoritative shared R53 ledger, all host receipts or a genuine shared lease. No UNKNOWN was replayed.

Seven isolated Python tests pass, including consumed and missing candidate semantics, missing/orphan markers, malformed identities and filenames, mixed roots, duplicate JSON keys and symlink refusal. An independent verifier checks archive-part SHA-256, counts, missing batch paths and missing closure/process markers. No worker, network execution, GPU or service modification occurred. Next reconcile available external receipts and genuine lease identities; do not use this offline audit alone to authorize inter-PC work.
