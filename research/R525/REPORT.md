# R525 — bind local worker executable identity to the SC117 plan

The v11 plan bound the local worker path but not its binary identity. The v12/r525 plan embeds the caller-supplied `VF_LOCAL_WORKER_SHA256` in each local rank's argv. It is required and must be lowercase SHA256. The SC117 coordinator now launches local ranks with `--guarded-local --expected-exe-sha256`; the worker checks `/proc/self/exe` as a bounded regular file, with stable metadata around the read, before starting the session protocol. A mismatch refuses before HELLO. The guarded remote path retains its existing memory gate and error category; local mode does not claim or simulate a remote resource gate. Local/SSH reporting and the requirement for an externally supplied expected plan for SSH are based on the fixed guarded-local argument rather than argv length.

The actual PC1 release worker, SHA256 `49216f6ce76a637be323dd0aa88c69e7788b4fa8ff13f5663ee103c5e4a22409`, accepted a matching digest, completed HELLO for rank 2 and SHUTDOWN/BYE with zero expert executions. A wrong digest refused with exit 2 and no protocol output; the guarded-remote wrong-digest case preserved its remote error category without opening a network connection. A no-worker preflight prepared two v12 plans with distinct expected local hashes; an independent JSON/SHA256 oracle reproduced both and a missing local digest was refused with an empty fresh ledger. Engine binary SHA256 `d860a589102b2beb862c25655b518066e73953c15972f294a65fc9b1cb0c1f39`. Plan A is `r525-16c50563c705726791409cef4b5c372b809504502fc26b6f44b9aae3a38ddad2`.

Rust binary tests passed in debug and release; after the final diagnostic-category adjustment both binary suites passed in release (six tests). The actual worker startup checks and 34 tokenizer/adapter/chat tests also passed on PC1 with the observed tokenizer and no skips. Builds used a CPU-only 3 GiB/no-swap/64-task/150% scope; the isolated worker and no-worker preflight used 512 MiB/no swap/16 tasks/one CPU. No model generation, expert execution, GPU, inter-PC worker or existing claim replay occurred.

This detects accidental binary substitution when the executed worker honors the guard; a malicious substituted executable could ignore it. The caller must independently authenticate the expected digest, executable, host, checkpoint and plan. This is not an attestation, a shared lease, a hardware admission or R53 reservation. Actual v12 generation remains unqualified; PC6 free swap is below the inter-PC floor. Next qualify the new worker and plan through a fresh local model run, and integrate real host identity and shared lease only under all required admissions.
