# R392 — complete patched donor dispatch in a CPU-only test

`check_reference_patch.py` now has an opt-in `full` mode that compiles and links the complete patched Strata fb58 `expert_source.cpp` and the real VoltaFabric C++ pool hook, rather than extracting only its prefix. Test-only stubs for every unresolved CUDA, peer/helper, old CPU fallback and architecture-specific entry abort if reached. The resulting test executable has no CUDA runtime dependency. A child deliberately enters the ordinary fallback and is stopped by an aborting stub, with core dumps disabled. The source patch remains in a private overlay; the donor checkout and live services are unchanged.

With `VF_STRATA_CPP_DONOR_FULL` explicitly set, the synthetic integration test executes the complete donor `expert_pool_dispatch_multi` function, which calls the real pool hook, binary client, Rust coordinator and two persistent native rank-session children. Two distinct batches match direct provider FP32 outputs. A GPU-resident expert is rejected before submission, and a layer mismatch latches failure without changing output. The rank-session and durable-ledger tests pass; this optional leg is not exercised unless the environment variable is set. The `full` test links aborting stand-ins outside the selected branch; it is not a full Strata model or GPU verifier build and does not exercise those branches.

The donor's CUDA verifier, its error and drain behavior, real checkpoints, external owners, inter-PC execution and generation remain unqualified. The candidate patch is not configured or deployed, and cannot establish a complete model. No GPU execution or consumed UNKNOWN was replayed; all hardware gates remain in force.
