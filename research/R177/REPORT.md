# R177 — admission expérimentale d'un placement inspiré de DeepInfer

R172 a démontré qu'un placement produit par la politique EPLB DeepInfer peut contenir deux copies d'un expert logique sur le même rang, alors que le routeur VoltaFabric refuse ces doublons. `admit.py` accepte une proposition physique→logique dans une frontière CPU privée et produit un candidat de registre Rust avec ordre résident. Il vérifie couverture des experts, unicité expert/rang, identité des rangs et epoch, capacités par rang fournies par l'appelant, tailles d'expert non nulles et owners préférés présents ; routes, coefficients et stamp sont copiés sans modification. Une erreur refuse la proposition sans modifier le problème d'entrée. Les capacités sont des budgets fournis, pas une réservation effective.

Six tests CPU valident nominal, doublon, capacité, couverture, identité/typage, owner préféré et déterminisme. Une vérification séparée a exécuté la vraie politique DeepInfer épinglée en CPU : le placement équilibré est admis puis accepté par le vrai CLI Rust `routing`; le cas hot avec doublon est refusé. Une énumération indépendante de 4 096 affectations synthétiques sur deux rangs a trouvé 432 propositions admissibles et 3 664 refusées ; 16 propositions admises ont aussi été passées au CLI Rust. Commandes : `python3 -B research/R177/test_admit.py`, `<a92-cpu-venv>/bin/python -B research/R177/test_donor.py`, `python3 -B research/R177/check_exhaustive.py`, puis `git diff --check`, toutes exit 0. Les tests rouges ont d'abord montré le module absent, puis deux défauts de contrôle d'owner préféré et de booléen epoch, corrigés avant validation.

Code original VoltaFabric inspiré de la forme des données DeepInfer, pas de code donneur copié. Ceci n'installe pas une politique EPLB dans le moteur, ne sélectionne pas dynamiquement une copie par token, ne migre aucun poids, ne réserve aucune mémoire et ne prouve ni optimalité ni comportement inter-machines/GPU. Les limites et les champs non validés de l'ensemble du problème restent soumis au vrai routeur Rust ; pas de modèle complet ou gain de vitesse. Le code est dans une branche de recherche locale, non publié et non promu au canonique.
