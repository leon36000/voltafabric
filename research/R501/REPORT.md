# R501 — bounded multi-turn text chat preparation

Parent GitLab R500 2aa2dbe8a2b53c52cd8ba162b897aff323f21719. The R494 SC117 text-only chat adapter now accepts an optional system message followed by alternating user and assistant messages ending with a user message. It supports at most eight messages, 4096 UTF-8 content bytes and the existing engine limits of 32 prompt tokens and 39 total input positions. The original `--chat` single-user interface remains supported; `--messages-json` reads a bounded JSON history from stdin with duplicate-key rejection. Unexpected fields, empty text, unsupported roles, ordering mistakes and overlong input are refused before engine launch.

The renderer implements only the observed checkpoint template's plain-text, no-tools, no-vision, thinking-disabled path. It inserts trusted message and thinking markers but makes every message content a plain tokenization span, preventing special-token literals inside supplied content from becoming formatting controls. It checks the complete control-token sequence. This is a deliberately limited template adaptation, not arbitrary Jinja evaluation; caller-supplied assistant history is not authenticated and is not a KV-cache continuation. Every call begins a new identified run and requires a fresh ledger and external resource admissions.

On PC1, 28 Python tests passed with the existing Strata venv and the hash-pinned observed tokenizer/template. Tests compare system and alternating histories against the actual Jinja template, verify literal-control containment and invalid order/roles/extra fields, prove oversize token inputs cause zero engine calls, and exercise an accepted 29-token two-turn prompt through a synthetic engine receipt. One initial bound test mistakenly expected a 32-token example to exceed 32; it was corrected to a genuinely longer input and the suite then passed. Python syntax compilation also passed. This batch has not run the new history through the real model; R498 is still a single-turn CPU result. No GPU, inter-machine worker, model generation, UNKNOWN replay or speed comparison occurred in this batch.
