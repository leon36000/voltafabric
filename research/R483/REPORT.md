# R483 — per-rank CPU worker endpoint configuration

Parent R482 commit 22561dd5964a8d5e4bb30722d552d4bd0c938581. The SC117 prefill executable previously launched the same local worker path for both ranks. It now constructs a separate `Endpoint` for rank 2 and rank 3 before opening model files or launching workers. The existing positional worker path remains the default for each rank. For an explicitly configured SSH rank, both `VF_RANK{2,3}_SSH_HOST` and `VF_RANK{2,3}_SSH_WORKER` must be supplied. The host is a constrained SSH alias and the worker path is an absolute path restricted to safe ASCII path characters. The invocation uses `/usr/bin/ssh -T`, `BatchMode=yes`, `StrictHostKeyChecking=yes`, and a 10-second connection timeout; no local shell is used. The controlled remote path cannot include shell metacharacters or whitespace. Authentication and host-key configuration remain external.

The complete successful receipt identifies each configured transport as local or SSH; it does not attest the remote host key, an R53 lease, physical memory, placement topology or network performance. The coordinator still loads verified weight blobs and sends them to sessions; this does not qualify a production network. SSH can involve a remote shell for command execution, so this intentionally admits only a single absolute worker path and no arbitrary command arguments. This changes no GPU, RDMA, weight format, routing coefficient, collector or no-replay contract.

Binary unit tests passed in debug and release, covering two distinct rank selections, local compatibility, missing paired settings, leading options, newlines, shell metacharacters and invalid paths. Targeted Clippy passed. Running the actual debug binary with a malformed host and separately with a missing paired path refused before opening nonexistent model paths or starting a worker. `/usr/bin/ssh` was present on PC1 and PC6; no remote worker, GPU or inter-PC test was launched. The code does not enforce the fleet-wide resource admission: a caller must verify all current gates externally before enabling SSH. In particular, PC6 swap remained far below the required 1 GiB. The endpoint change is not a claim that real distributed generation works.
