# R584 — same-host contraction experiment for the R428 witness

Tested whether disabling compiler floating-point contraction alone resolves the SC117 layer-2 expert-255 cross-build discrepancy. Two fresh PC6 AArch64 CPU builds used current `provider.cpp`, the same pinned GGML revision `3cf03257f219afbe7334045ff7c6a06ac68c627d`, same compiler, `-O3`, `GGML_NATIVE=OFF`, and identical retained R428 input and expert bytes. The second adds `-ffp-contract=off` to both C and C++. All 26 compile command records have identical source sets and command lines after normalizing build paths and removing that one option. This does not disable explicit architecture intrinsics and does not isolate any particular instruction.

Relative to R428's retained PC1 staged reference, both fresh outputs still have 1,167 violations of `1e-7 + 1e-3*abs(reference)`; maximum errors are respectively 5.401955172601447e-5 (default) and 5.4018620403439854e-5 (no contraction). The two PC6 outputs differ in 991 of 2,560 f32 values, with maximum 3.725290298461914e-9. The no-contraction output exactly matches the retained R575 PC6 output SHA256, while R575's PC1 output retains zero violations against that staged reference. This rejects the narrow hypothesis that disabling compiler contraction alone fixes this specific PC6 threshold discrepancy. It does not determine the cause across hosts, prove model quality, justify changing tolerance, or resolve the original full scalar R428 failure.

Both new probes ran as separate local CPU-only scopes with 512 MiB memory, zero swap, 50% CPU and 32 tasks maximum. No model worker, GPU, network execution or UNKNOWN replay occurred. `PLAN.json` records binary/source/input hashes before either probe; `verify.py` independently checks retained input and output data via Python struct and generates `RESULT.json`. Raw model-derived bytes remain local and are required for reproduction. Future distributed admission still needs a defined heterogeneous-producer numerical contract, authoritative R53 reconciliation, and a genuine shared lease.
