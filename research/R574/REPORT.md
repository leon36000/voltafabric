# R574 — observed donor parity and cross-build numerical divergence

On PC6 AArch64, the pinned and unmodified Strata generic CPU functions `native_fmt`, `native_quant_act`, `native_gu_rows`, `native_quant_h` and `native_down_rows` (Strata fb58e0dbc8399662c0e47c76578c6e878b14f6cf, MIT), linked to pinned llama.cpp GGML 3cf03257f219afbe7334045ff7c6a06ac68c627d (MIT), were compared with VoltaFabric's native CPU provider. R386 covered synthetic packed weights; this test uses R428's real SC117 layer-2 expert 255 and token-0 activation. The 1,971,200-byte expert slice and 10,240-byte activation match R539/R428 SHA256s. Arithmetic, GGML and quantizers are shared: this comparison checks the adaptation against the donor, not independent mathematical correctness.

All 2,560 provider output floats are bit-identical to the Strata generic result on PC6. Against the retained PC1 x86_64 R428 staged f64 down-reference, however, 1,167 elements violate `1e-7 + 1e-3*abs(reference)`, max absolute difference 5.4018620403439854e-5. On PC6, intermediate 541 is -0.056449007242918015, normalized -120.50001525878906, Q8 code -121. R539's PC1 vector path recorded -120.49999237060547 and code -120. These are distinct architecture/build/arithmetic contexts; this is evidence of a cross-build discrepancy, not proof that ISA alone caused it. The original R428 full scalar failure (1,169) remains unchanged and cannot be reclassified as a pass. The PC1 reference is a staged reference, not the captured raw output of the donor engine.

The detailed diagnostic returned exit 10 to flag the cross-build reference violations. A corrupted activation was rejected with exit 5 because it differed from the input embedded in the retained reference. Both diagnostics ran locally on PC6 in CPU-only 512 MiB, zero-swap, 50% CPU scopes, with no worker, GPU, R53 reservation or UNKNOWN replay. The first probe had an external plan before execution; the detailed source and binary identity were recorded after its diagnostic run and are not represented as a pre-execution plan. Raw weights, activation and reference are not published. Source compiles with C++17 `-Wall -Wextra -Werror`. No model-level quality, performance, GPU or distributed equivalence is implied.

Next: require an explicit cross-producer numerical contract and verify the actual collector with divergent architecture outputs; reconcile authoritative R53 and shared lease before any inter-PC worker. Do not silently relax the original scalar threshold.
