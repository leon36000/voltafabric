# R475 — recent-use ordering for local CPU expert residency

Parent R474 `68cdc69227ecde2ff3b08473299110af66e16698`. The Segment now records, per layer and expert, the most recent successfully completed position that selected it. Between globally committed positions, the bounded eviction planner orders eligible residents by oldest use first, with never-selected residents first and deterministic layer/expert/rank tie breaks. It still excludes the most recent route, preserves at least one resident per worker, preplans the entire trim, checks binding and accounting and never retries an uncertain operation. Acknowledged eviction removes the resident's age entry; a later route-driven re-admission records a fresh use only after the layer commits. If a later layer fails the entire Segment remains poisoned, so partially updated recency cannot drive another operation. This is an in-memory local heuristic, not a predictor, distributed placement algorithm, persisted cache or latency guarantee.
