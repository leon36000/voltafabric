# R430 — SC117 short-context QSA CPU prefix

Parent R429 `13f926e5a0b71259827b718ed116915de591f2bb`. Introduces `qsa_cpu::State`, a bounded CPU grouped-query attention reference with FP16 K/V cache, stable softmax and sigmoid gate. Up to 2,051 cells it attends to all cells; this matches the identity-selection bound documented by Strata fb58 `include/strata/kernels/qsa.hpp` for indexer top-k 2048 and block size 4. It refuses larger capacities; sparse selection and indexer cache are not implemented. Query and key passed to the generic core must already be normalized and rotated. The state stages a candidate and rejects stale or foreign commits. This cache commit is caller-controlled and is NOT yet bound to a local reservation, the expert Collector or whole-layer completion; do not treat it as failure-atomic production layer state.

`sc117_qsa_stage` adds resident checkpoint-bound layer-3 HC read, Q/K/V projections, per-head weighted RMS norm, default-base NeoX partial RoPE (64 of 256), grouped attention, gate and output projection. Checkpoint GGUF types are IQ4_XS for Q, Q6_K for K/V, Q8_0 for output; Q is split into two resident 6,144-row matrices. Shapes and span SHA-256s are in `fixtures/r430/layer3.json` (SHA `f0c4bdadf42bb502195a7314d3d73661d63687ca161e420e28381a45c4ddbd21`); hashes are local observations, not publisher authentication.
