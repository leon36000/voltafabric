# R554: observed prefill routes through a grouped expert batch

The R552 layer-3 QSA trace includes the actual residual, attention output and injection for 92 positions. `vf-sc117-prefill-route-trace` hashes that trace and the FFN manifest, then uses the production FFN stage to recover the layer-3 activations and gate choices for positions 0 and 1. Their first ten admissions, and the seven new admissions of position 1, match the original R552 admission order. The three already resident choices in position 1 were not re-admissions. The inputs were generated by the real CPU model run, not synthesized. This is reconstruction from an observed trace, not a new end-to-end prefill.

`vf-sc117-observed-prefill-batch` loaded the 17 locally observed, digest-checked expert slices into two guarded local Rust rank sessions. Rank assignment was selected from the R552 admission record; local IDs were newly and densely assigned, rather than asserting the original layout. The two actual ten-expert routes and f32 gate coefficients were executed as a single two-token batch. All 51,200 raw FP32 values matched independently invoked ungrouped `Resident::forward` bit-for-bit. This baseline uses the same GGML implementation and is not an independent model oracle. The separate Python scalar check decoded FP16 and accumulated each original route in order with its coefficient once; all 5,120 f64 Collector values matched bit-for-bit. Both workers reported two raw executions and closed cleanly.

The first launch refused the relative ledger path before any reservation or worker was started. Its marker is preserved. A fresh attempt used a different plan and empty absolute ledger; both subsequent claims are `RESERVED_UNKNOWN_NO_REPLAY`. No GPU, network transport or performance comparison was involved. The previous expert-255 scalar discrepancy and model-wide independent oracle remain open. A genuine layer-major prefill transaction still requires provisional attention/PLE state and atomic rollback; this batch experiment does not implement that transaction.
