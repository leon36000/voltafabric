# R400 — two real SC117 experts, local CPU scalar check

`real_expert_oracle.cpp` runs the VoltaFabric GGML native provider and compares every output row against a separately accumulated scalar reference: it dequantizes each gate/up/down weight row, uses double scalar products and re-quantizes the intermediate. Activation quantizers, weight dequantizers and type metadata are still GGML implementations, so this is not a fully independent GGML or model oracle. It uses one synthetic sine activation, an explicit tolerance of `1e-7 + 1e-3*abs(reference)`, admits only layer 0 experts 0 or 1, and is an explicitly invoked CPU diagnostic, never an automatic CTest or a generation engine.

On PC1, an isolated `nice -n 15` CPU-only build in `/home/pc1/NAOS/vf-r400-cpu-oracle` linked existing Strata GGML CPU build objects and static ggml-base; no service or installed package was modified.
