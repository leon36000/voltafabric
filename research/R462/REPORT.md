# R462 — two-token prompt prefill on the 48-layer CPU path

Parent R461 `b5d7db4b53f1c8b63555c4ee8feb326ce3e93c97`. The experimental prompt runner now accepts one or two ordinary prompt tokens and up to two greedy predictions. `vf-sc117-prefill-greedy` commits each supplied token through the same persistent 48-layer segment before evaluating the head at the last prompt position. It feeds the first generated token for the second prediction and stops on EOS. QSA capacity is three positions. The receipt records prompt tokens separately and validates the input sequence, three-position residual hashes and generated-logit hashes before decoding. Old one-token receipts remain accepted. No chat template, sampling, longer prompt, longer generation, distributed transport or GPU execution is claimed.
