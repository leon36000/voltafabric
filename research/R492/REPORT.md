# R492 — tokenizer-selected EOS bound into generation

Parent GitLab R491: 195528b00302f902f6b6ab13f48e494cbe0a3fbb. This is VoltaFabric integration code, not a new donor import. The pinned MIT-licensed Strata tokenizer and GGML provenance are recorded in R460/R379.

Previously the tokenizer supplied EOS to the Python decoder, while the SC117 generator independently stopped only at hard-coded 248046. A mismatching authenticated tokenizer could therefore cause extra execution after its EOS or premature engine termination. The prompt runner now validates EOS as a tokenizer control token, passes it explicitly after the output limit, and rejects the entire receipt unless the engine reports the identical integer EOS. The engine validates the EOS vocabulary range before touching paths or launching workers, rejects it in the input prompt, uses it to stop greedy generation, reports it, and binds it to the version-4 worker plan. Direct callers omitting the optional argument retain 248046. The runner and updated generator must be deployed together; older binaries cannot accept the new invocation. The caller still authenticates model and tokenizer compatibility, and this does not certify arbitrary tokenizers or models.

Three Rust unit tests passed in both debug and release; targeted Clippy passed with -D warnings. A separately computed Python JSON/SHA256 plan vector matches Rust and changes with EOS. Two direct local CLI checks rejected an out-of-range EOS and an EOS prompt before opening nonexistent model paths, with no stdout. On PC1, the existing Strata venv's regex 2026.9.10 ran 21 Python tests: 20 passed and the observed-pack test was skipped. Tests verify forwarding, valid early EOS receipt, rejection of wrong/missing/boolean receipt identity, and refusal of a non-control EOS before launch. An initial PC6 Python test could not import regex and is not counted as a pass. No generation, model loading, cross-host worker, GPU execution, or speed measurement was attempted in this batch. Existing UNKNOWN claims were not replayed.
