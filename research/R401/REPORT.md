`real_sc117_session_check.py` is an explicitly invoked one-shot local diagnostic. It takes caller-supplied observed SHA-256 values, creates a fresh UUID run and local ledger directory, uses two distinct actual workers on ranks 2/3, and compares the complete unweighted FP32 rows with the R400 scalar reference for the same exact synthetic activation. It does not establish trusted checkpoint provenance or retry an unknown attempt. The reference shares GGML quantization/dequantization; inputs are synthetic even though weights are real. The optional oracle output file contains 2560 FP32 input values followed by 2560 FP64 scalar results on little-endian hosts.
