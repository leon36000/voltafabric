# R600 — backend scalaire lié au plan de génération CPU

Le lanceur de qualification SC117 choisit explicitement `VF_SC117_NATIVE_BACKEND=vector` ou `scalar`. Le mode vectoriel reste le défaut et conserve exactement son identité de plan antérieure. Le mode scalaire exige l'option de compilation `native-scalar-reference`, applique au plan existant un domaine SHA-256 distinct et exige `VF_EXPECTED_PLAN_ID` même pour des workers locaux. La comparaison avec cet identifiant fourni par le contrôleur n'est pas une authentification, une lease ou une réservation. Le backend scalaire est refusé sur SSH tant qu'il n'est pas qualifié entre machines.

Le choix est inscrit dans les sorties de plan et reçus ; il sélectionne le chargement initial scalaire ou vectoriel par `Session`. R599 sélectionne ensuite l'extension dynamique selon le backend confirmé. Le plan de base continue à lier les endpoints et les digests d'exécutables ; aucun changement de backend ne conserve l'identité de plan scalaire/vectorielle. Les protections R53 et les UNKNOWN sont inchangées.

Le test du plan vérifie la séparation des domaines, la conservation de l'identité vectorielle, le refus d'un plan scalaire absent et le refus de SSH. Le hash du cas fixe a été calculé indépendamment avec Python hashlib. Un autre test charge les deux experts initiaux via `owners`, deux vraies `Session` locales et deux pairs Python simulés qui exigent l'opcode scalaire et accusent le scellement. Le pack de test est un fichier creux de 50 292 326 400 octets logiques, sans blocs alloués observés, et ne contient aucun poids réel. Aucun worker VoltaFabric, génération complète, GPU ou opération réseau n'est lancé.

Les 16 tests du binaire passent en debug et release avec l'option scalaire ; les 15 tests applicables passent sans elle. Clippy ciblé passe avec l'avertissement historique `dead_code` autorisé ; rustfmt ciblé passe. L'oracle scalaire et ses limites sont documentés en R590–R595. La génération complète avec ce mode, les producteurs inter-machines, l'authentification du plan et la réconciliation R53/lease restent à qualifier.
