# R481 — native execution counts and qualified local CPU generation

Parent R480 GitLab commit a25331e2d8e91070649e52f0a0bd3124dbee34bf. The R480 attempted shutdown fix compared worker BYE counts with `Session.traffic.execs`, but native GGML EXECs did not update that counter. This change increments the checked counter on a successful native request send. The prefill binary now closes each session paired with its own coordinator counter and requires clean exit, no kill, no error, BYE equal to that counter, and a count no larger than committed positions. Empty-route ranks legitimately execute fewer times. A lost or failed request still poisons the batch; there is no automatic replay or partial output.

A fresh bounded CPU run on PC1 used a distinct R481 identity and ledger, 48 layers, 96 actual child workers representing two local rank labels, prompt `Hello!`, nine input positions and eight greedy predictions. It produced ` We’ve noticed that you haven’t made`. All 96 workers closed cleanly with matching execution counts; 15 executed fewer than nine times (minimum three). Per-rank payload limits were 1 GiB and 2 GiB, global limit 3 GiB. Final accounted payload was 770380800 and 1486131200 bytes. The receipt reports 870 evictions, 1874 admissions and 213 re-admissions.

verify.py reconstructs the receipt and checks the execution counts, budget accounting, claim identity, protected routes, expert digests and previous independent observations. It verifies exact agreement with R475 for tokens and every embedding, layer output and logit hash. Independent local source observations cover all 1757 distinct experts (R481 introduced no previously unobserved expert). This confirms consistency with the pinned local data, not publisher authentication. The 1302 claims are preserved, with their existing status RESERVED_UNKNOWN_NO_REPLAY; they must not be replayed. The claims themselves do not prove operation success, whereas the separately checked complete receipt records a successful run.

The close-predicate test passed in debug and release and Clippy passed on library and binary. Python classifier tests ran 14, 13 passed and one observed-pack test skipped. An added two-child regression assertion was not run to completion: Cargo attempted to compile all integration-test binary targets and the compile was stopped. The real 96-worker run exercises the updated native path. The worker execution counts are emitted in layer/session order without separate layer labels.
