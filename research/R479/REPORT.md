# R479 — identify the rejected shutdown

The R477 error classifier expected raw Rust error messages but `voltafabric::Error` displays `INVALID_INPUT: ` before the message. R479 fixes the exact allowlist and adds a category for the prefill binary's worker shutdown refusal, plus the numeric subprocess exit status; arbitrary stderr and stdout remain private and no retry is performed. A regression test failed with the old classifier and passes with the corrected form. On PC1 the tokenizer adapter tests ran 14 tests, 13 passed and one observed-pack test was skipped. A Rust source test verifies the actual error display prefix.

A fresh bounded local CPU run used the R478 rank-aware headroom algorithm, distinct R479 identity and a fresh ledger. The wrapper reported `worker_shutdown`, exit 1, and published an empty result. There were no rank workers remaining. The exact reason within the shutdown predicate was not recorded; it would be unsound to infer that it was solely an execution-count mismatch. The old binary rejected a worker unless it executed every position, while the dispatcher sends requests only to ranks with nonempty slots: this is a concrete incompatibility and a testable hypothesis, not proof of the specific R479 cause.
