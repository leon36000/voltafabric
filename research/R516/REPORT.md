# R516 — plan-only preflight and expected identity

Parent GitLab R515 9539edf2747fa73534df74aa0efb3acc5e6f0647. The SC117 CPU prefill executable now accepts `--plan-only` immediately after the binary name, with the same positional inputs and environment as a run. It validates the prompt, endpoints, native index, pack length and payload budgets, prints only the plan ID and prompt digest, and exits before loading model weights, opening the ledger, or starting workers. Input files are opened for metadata/index validation. The option is not a hardware admission or reservation.

For a normal run, `VF_EXPECTED_PLAN_ID`, when present, must equal the actual computed plan before weight loading or worker launch. For any SSH endpoint it is mandatory; local runs remain compatible without it. The Python prompt runner validates the supplied expected-plan format before invoking its engine, and if supplied, compares the returned plan ID before decoding text. This links the caller's chosen identity to the process and receipt but does not authenticate the caller, prove a plan was admitted, attest the remote host/worker, reserve resources, establish a shared R53 lease, or prevent an untrusted engine from ignoring the environment. Exact model/checkpoint bytes are not fully covered by the current plan. A correct external admission and all existing protections remain necessary.

A real PC1 no-worker test used the existing observed index/pack and a configured SSH-shaped endpoint. `--plan-only` returned r512-cf4fa68ecdb51f3d48e1b3f79a22e5a7b8a5c3f27016d355db0011d72f0581c9; verify_plan.py independently reconstructed its JSON and SHA256. Missing and incorrect expected identities each refused with no stdout, no worker and an empty fresh ledger. No SSH transport or GPU was executed. A retained R514 receipt with the real tokenizer was accepted under its matching expected identity and refused under a different one, without executing a model or replaying a claim. The worker binary is pinned in the synthetic plan; host identity is not authenticated by the test.

Four Rust binary tests passed in both debug and release, targeted Clippy passed, and 31 Python tokenizer/adapter tests passed on PC1 with the real observed tokenizer and no skips. PC1 build and preflight used isolated scoped workspaces, no swap and bounded CPU/memory. PC6 swap remains below the 1 GiB inter-PC gate. No new generation, worker, GPU, SSH test, shared lease or UNKNOWN replay occurred.
