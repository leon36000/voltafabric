# R388 — persistent local native-expert coordinator

`vf-strata-native-bridge` is an opt-in CPU-only framed process coordinating the native GGML rank sessions. It receives a pinned routing template, SC117 index, regular pack path, caller-supplied trusted per-expert digests, local ledger and local worker executables. It checks rank/registry/binding coverage, reads only selected experts, verifies index and per-blob SHA-256 and stable file descriptor metadata, then loads and seals residents once. A nonblocking open refuses a FIFO rather than hanging. These checks bind admitted spans to caller-supplied hashes, not the identity or integrity of the complete checkpoint.

For each bounded Strata-style request it accepts a batch number, FP32 inputs, expert IDs and final ownership kinds, runs CPU-owned slots through the negotiated unweighted FP32 sessions, and emits a complete framed reply containing only CPU positions and rows. External rows remain the caller's responsibility and no gate coefficients are applied. The existing local durable batch claim is retained; errors close the coordinator without a completed reply. The client must parse the complete frame before writing, handle transport loss as UNKNOWN and never replay it. The local ledger is not R53 or a distributed lease.

A local integration test creates a sparse synthetic file with the SC117 logical length and only two small allocated expert blobs, launches the actual coordinator and two actual rank-session children, verifies two successive exact FP32 batches against separately requested provider output, then shows that replay is rejected both in the same process and after a fresh coordinator starts. It also checks clean shutdown, bad digest refusal and nonblocking FIFO refusal. No actual model payload is used. The initial test exposed a blocked FIFO; it was terminated as a local synthetic test and the nonblocking-open fix was retested.

This is a usable local coordinator protocol, not an attached Strata callback: the caller must establish actual final-kind provenance, coordinate GPU/peer waits and error handling, and apply routing weights once. No real checkpoint, inter-PC workers, GPU, model-wide execution or text generation is qualified. Details and protocol are in `adapters/native_ggml/NATIVE_BRIDGE.md`; provenance of Strata/GGML versions and licenses is in R379/R386.
