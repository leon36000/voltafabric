# R398 — bounded observations of two actual SC117 experts

`tools/observe_sc117_experts.py` computes up to 16 selected expert SHA-256 digests from a regular SC117 pack, with 64 KiB reads, the pinned index hash and a before/after descriptor identity check. It emits a complete JSON result only after success, rejects duplicate/out-of-range selections, FIFOs, symlink final targets and incorrect index or pack size. The result is expressly an observation, not checkpoint authentication. It does not establish the provenance or integrity of unobserved data and must not silently become an authoritative trusted manifest.

A read-only invocation on PC1 inspected 4,352,000 payload bytes, without copying them, on `/home/pc1/Strata-data/packs/sc117_abliterated_iq3_s/experts.bin`. The pinned index SHA-256 was `adba4968661f3d59f749a676a87948e29236c81997f649f5526daf71148edc24`. The stable descriptor was device 66312, inode 13631491, length 50292326400, mtime_ns 1792010935757642405, ctime_ns 1792010935942648543. Observed layer 0 expert 0 SHA-256: `f13d07f6ff33a274c4b22903c00ac13aafee621849c47e995ae133f5f61ca465`; expert 1: `cf78946c34e7974c84f524cc2c61b6a8a493d0a70a8866259a27a75a2b97dadc`. A separate earlier bounded read produced the same two hashes. This provides no full-pack digest or link to an authoritative upstream checkpoint.

The local test uses a synthetic sparse SC117-sized file, checks two exact hashes, and confirms duplicate/out-of-range and FIFO refusal without partial JSON. No GPU, real weight execution, inter-PC worker, model generation or consumed UNKNOWN was used. PC6 swap free was about 230 MiB, below the inter-PC admission threshold.
