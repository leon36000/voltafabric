# R122 — préparation isolée de la couture Skinny

Un préparateur privé vérifie le wheel 1Cat R121 et ses deux fichiers d'origine, puis les deux patches du donneur épinglé et `adapters/skinny_moe.py` au moyen de SHA fixes. Il vérifie la syntaxe des patches et refuse un wheel modifié, des membres manquants ou ambigus, un module skinny déjà présent, un fichier source modifié, un lien symbolique ou une destination déjà existante. Il écrit séparément les originaux et les trois fichiers candidats dans une destination nouvelle, puis un manifeste final. Une erreur d'écriture peut laisser un répertoire partiel à réconcilier. Il ne modifie ni le wheel ni une installation et ne constitue pas un chargeur de production.

Huit tests unitaires CPU synthétiques passent sur PC6. Le premier test a d'abord échoué parce que le module préparateur n'existait pas. Le premier transport de données vers PC4 a échoué dans le parsing JSON avant la création de destination : le terminal limitait la longueur de ligne. La seconde tentative a corrigé uniquement le mode du terminal ; elle a utilisé les mêmes octets et a produit le paquet privé, exit 0, à `/srv/zone-tempon/r122-skinny-overlay-20261028/prepared`. `pc4-receipt.json` lie le SHA du préparateur et les fichiers. Aucun ancien essai GPU ou modèle n'a été rejoué.

Sur PC1, l'adaptateur VoltaFabric a été lu, haché puis exécuté comme module Python dans l'environnement existant CPU : Python 3.12.14, Torch 2.10.0+cpu, les trois signatures sont présentes. La sonde n'invoque pas de GPU et n'importe pas 1Cat-vLLM. Elle n'établit ni la compatibilité du modèle, ni l'export natif, ni le fonctionnement de la couche. La totalité des autres patches du bootstrap, les dépendances et l'environnement 1Cat restent à admettre ; les fichiers préparés ne sont pas installés.

Vérification : `TMPDIR=<répertoire Naos privé> python3 -B research/R122/test_overlay.py` — 8 tests, exit 0 ; analyse syntaxique Python exit 0. Le wheel existant est inchangé, les fichiers canoniques et les services voisins n'ont pas été modifiés.
