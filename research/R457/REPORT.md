# R457 — reusable bounded SC117 CPU expert source

Parent R456 `0ebf67f54eaa425181b48a3ffb1865c3bc68a93a`. `sc117_expert_source` implements the existing `MissingExpertSource` seam using R456's checkpoint-slice digest and the native pack's digest-checked reader. One source accounts for initial residents and later admissions across a segment, checks the run/model/plan/epoch and nonzero attempt, bounds payload bytes with checked arithmetic before reading, and verifies that each layer's registry and rank order agree with its accounted residents. It rejects duplicate experts and slots, missing or extra ranks, inconsistent epoch, and mismatched accounting. Placement balances the configured ranks deterministically. A payload is charged before the worker append, conservatively retaining that charge if the acknowledgement is uncertain; the segment's existing error path poisons it and refuses partial output.

The caller must accurately enumerate every initial resident and reserve its budget before loading it, provide exclusive control over the represented sessions, and authenticate the index, model provenance and checkpoint metadata. This version intentionally allows at most one copy of an expert per layer and performs no eviction. The cap covers resident expert payload only, not full process RSS, stage weights, buffers, worker overhead, GPUs, other segments or machines. The checkpoint slice comparison proves local consistency, not publisher authentication.

One fresh CPU-only PC1 run used the reusable source with real SC117 layers 0–7, PLE and token IDs 42 and 73. Sixteen fixed seed experts and 134 route-selected admissions consumed 295,833,600 bytes of a 512 MiB cap; all 16 local workers completed both positions and returned clean BYE. Routes, per-layer hashes, seed hashes, all admission bindings and both output hashes match R456. The 150 digest values thereby match the independent local pack/GGUF slice observation retained in R456, not a new independent full-layer oracle. The in-process preview still shares numerical components and tokens were supplied, not generated.

Two focused source tests passed in debug and release, covering budget edge/overflow, registry and ordering mismatch, duplicate/unknown ranks and deterministic placement. Six existing segment tests passed in debug and release, including atomic failure and rejection of a substituted expert. Strict native-feature Clippy and targeted rustfmt passed. PC1 source and diagnostic hashes match local. Sixteen claims in `CLAIMS.json` remain `RESERVED_UNKNOWN_NO_REPLAY`; no GPU, inter-PC worker or R53 hardware lease was used and no worker remained after the run.
