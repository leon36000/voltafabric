# R425 — Reservation-bound SC117 local CPU layer boundary

Parent R424 `4b1bb5b74b9ddbec21f0e8f7f874dc0eafd2260b`. Introduces an opt-in `sc117_bound_layer::Routed`: it consumes a GDN proposal only if a still-valid local reservation, attempt, ledger directory and the exact residual bytes match the proposal; derives post-attention and routing from that proposal; computes the shared output from that exact routed activation; builds a worker `RoutingProblem` from its own immutable choices and activation, not caller-provided routes; and wraps the collected result with an opaque producer marker. Commit requires the shared result and collected result to come from the same bound object, then delegates to the existing native GDN commit, which checks stamp, attempt, ledger and state token. Caller still supplies a valid registry/placement and trusted manifests; these are checked for routing validity but placement/weight trust is not authenticated by this wrapper. The existing unbound and experimental APIs remain available, so this is not a global enforcement guarantee. The local ledger is not the R53 hardware lease or distributed locking; no crash-safe GDN checkpoint is implied.

Two local preflights loaded the actual SC117 layer-2 tensors but used distinct synthetic residuals and newly created claims. They rejected a changed residual and an unrelated ticket, successfully formed a route and shared result, and confirmed GDN state remained at token 0 without dispatch. The 8 claims are recorded in `CLAIMS.json`; all remain `RESERVED_UNKNOWN_NO_REPLAY`, including claims not dispatched. Never replay them. The second preflight tested the final code after adding an explicit residual length bound. No workers, GPU or inter-PC operation were executed; the dispatch and final commit of the new bound path remain unqualified and require a separate fresh test, with real routing/owners and independent validation. R423 exercises the earlier unbound commit path, not this new wrapper.

Targeted debug and release tests `native_ledger` (4), `sc117_gdn_stage` (1) and `sc117_shared_stage` (1) passed. Targeted Clippy passed with warnings denied after an explicit argument-count allowance for the dispatch interface; the initial Clippy run reported that lint. Formatting check passed. The first attempt to run those tests failed because the isolated project initially lacked `tests/native_ledger.rs` and then its `.runs` directory; copying the existing test and creating that directory fixed the environment. No prior failed claim was replayed. Numerical oracle evidence for the underlying computations is R422–R424; the new binding preflight is a rejection/identity check, not an independent numerical oracle.

Next: exercise a fresh bound dispatch and commit using a distinct workload, compare the live collector and final residual against independent references, test rejected/missing worker output without advancing GDN state, then make the bound layer usable across tokens and connect subsequent layers toward generation.
