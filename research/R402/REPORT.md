# R402 — real SC117 router weights to ten local resident experts

VoltaFabric now has an explicit SC117 CPU router reference: it admits the exact 512-by-2560 BF16 matrix, rounds finite inputs to BF16 nearest-even, uses bounded scalar f64 dot products rounded to f32, full softmax, stable descending selection with expert-index tie-break, the donor's `2^-14` renormalization clamp and f32 coefficients. The top-k semantics are adapted from Strata fb58 `src/kernels/cuda/router_top10.cu` (MIT), but the CPU dot/reduction is not the CUDA implementation and bitwise GPU equivalence or agreement near selection ties is not claimed. Unit tests cover ordering, ties, normalization and non-finite refusals. The CPU executable verifies an operator-supplied SHA-256 for the router span and checks pack metadata; it is an explicit diagnostic, not a model loader.

An independently written NumPy BF16/double-matmul/softmax calculation selected the same IDs, with maximum f32 coefficient difference 2.6097869837427012e-09. This checks the CPU reference on one activation, not GPU parity or a real model activation.

Each selected real expert was locally compared with its source GGUF slices using R399; the bounded observations are preserved in `SELECTED_OBSERVATION.json`, not claimed as publisher-authenticated identity. Two real local Rust rank-session workers each loaded five experts. The one-shot diagnostic verified all ten unweighted FP32 rows against separate scalar expert references and applied the CPU router coefficients once in a local f64 weighted sum. The maximum row difference was 2.9051194379270916e-11; the maximum weighted-sum difference was 4.821522602829406e-12. This weighted sum is a Python diagnostic, not proof of the Rust Collector's order or the donor CUDA combine.
