# R437 — actual SC117 QSA projection formats across all twelve QSA layers

Parent R436 `8ca7ccb23dc88529d1e0ed6a24e33ea958d73cc9`. `sc117_qsa_stage::Manifest` now accepts explicit per-layer GGML Q/K/V formats Q4_K (12), Q5_K (13), Q6_K (14) and IQ4_XS (23), validates exact fixed row geometry and rejects unsupported or missing formats before reading weights. Only the existing layer-3 legacy manifest may omit the three type fields; its original types remain the defaults. Query halves must be contiguous and are independently size/hash checked. These GGML formats are distinct from QPN2/NVFP4 and MXFP4.

`scripts/r437_qsa_manifests.py` generated 12 small manifests under `fixtures/r437` from the existing local GGUF and Strata dense index, binding every span to a SHA256. All 12 layers 3, 7, ..., 47 loaded their real Q/K/V/output matrices and produced a first-position QSA prefix on PC1 CPU using one synthetic residual. The test includes the actual mixed format cases: layer 7 IQ4_XS key, layer 11 Q4_K query and Q5_K value, layer 19 Q5_K query, and layer 31 Q6_K query. These hashes and model identity are observations, not authenticated publisher provenance.

The scalar reference `check_sc117_qsa_formats.cpp` independently decodes and accumulates sampled rows, while sharing GGML quantizers and decoders. It checked 11 query, 5 key, 5 value and 7 output rows per layer: 336 sampled rows in all, 48 projection checks, maximum absolute discrepancy 3.28e-7. The full results and output hashes are in `RESULT.json`, SHA `0dfae88bc074264c2413388db93b328d52e5385190cf00af7fb7bd3e62033f8c`. These are sampled projection checks; they do not independently validate every row, attention cache, the layer FFN, complete model or generation. The standalone prefix checks submitted no worker request or durable claim and do not replay UNKNOWN operations.

Two targeted rejection tests passed in debug and release, including missing/unsupported type and noncontiguous query halves. Native-feature Clippy with warnings denied and rustfmt passed. No GPU or inter-PC worker ran. The matrix boundary reuses the pinned MIT GGML/llama.cpp and Strata CPU ideas documented in `adapters/native_ggml/README.md`; donor quality is not assumed.
