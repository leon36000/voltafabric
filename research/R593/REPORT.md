# R593 — seven explicit SC117 scalar reference format pairs

Extends the opt-in R592 scalar diagnostic to the seven gate/up–down combinations present in the observed SC117 index: IQ3_XXS/IQ4_NL, IQ3_XXS/Q2_0, IQ3_S/IQ4_NL, IQ3_S/Q2_0, IQ2_S/IQ4_NL, IQ2_S/Q2_0, and IQ4_XS/IQ4_NL. These GGML formats remain distinct from each other and from MXFP4 and NVFP4. The caller supplies explicit format IDs; unsupported pairs, wrong byte geometry and invalid values fail without changing output. The previous IQ2_S/IQ4_NL API remains as a wrapper. The separate target remains disabled by default and is not a worker backend, a routing implementation or the FP16 Collector.

Synthetic tests exercise all seven pairs with zero and nonzero weights and compare every unweighted f64 output to separately accumulated scalar results; these use shared pinned GGML quantizers/dequantizers, so they are not an independent format decoder. Tests also cover unsupported pairs and wrong sizes. Release CTest and direct debug `-O0` pass; the retained real expert-255 R592 comparison still passes through the old wrapper. The first new test failed to compile before the generic API existed.

For each pair, one bounded expert-0 slice was read from its observed SC117 layer and matched the corresponding R588 recorded seed digest; the descriptor's identity and timestamps were stable through extraction. Four FP32 inputs were used: two retained R428 layer-2 activations and two scaled variants. Inputs are reused across layers as numerical probes, not claimed to be their actual layer activations. All 28 unweighted f64 output captures are bit-identical between PC1 x86_64 and PC6 AArch64 and nonzero and finite. `verify.py` independently checks captures, source identities, pairs and prior seed records. Raw model-derived bytes stay local. Two CPU-only scopes used 512 MiB, zero swap, 50% CPU and 16 tasks, with externally prepared plans; no GPU, network worker, R53 lease or UNKNOWN replay was used.

This extends a bounded diagnostic reference, not a production arithmetic contract, cross-machine determinism guarantee, authenticated checkpoint or whole-model oracle. The shared ledger, cooperative lease, actual distributed execution and original vector/scalar discrepancy remain open. The GGML decoder/quantizer code is from pinned llama.cpp `3cf03257f219afbe7334045ff7c6a06ac68c627d` (MIT), with adaptations and limits recorded in the source.
