# R436 — two positions in one QSA–GDN CPU segment

Parent R435 `11d7d5e4954bdc0f46884f2ce3945243bcbb6dfa`. One fresh, identified local CPU execution advanced the same resident layer-3 QSA and layer-4 GDN Segment through two different synthetic input vectors, with positions/batches 0 and 1 and strictly increasing attempts. A no-worker preview computed each position in order with persistent QSA and GDN state; its selected expert unions were loaded once into the four CPU workers. The union contained 16 layer-3 and 18 layer-4 experts; routes changed between positions. Each worker reported two executions and exited normally. Both final residual vectors compared equal as f32 values to the in-process preview, which shares the native provider and Rust completion code and is not an independent end-to-end oracle.

`RESULT.json` (SHA `50c95381850fb50625e926c7da9aebf9218cfb6ac263fa222bf48d2f8f596025`) contains the run, attempts, routes, observed unions and input/output hashes. The result vectors are not model-generated tokens. `WEIGHTS.json` (SHA `4e41041bf3b5665b4272d0c2420c94e41b269893e71bf9acb09dc3c285edf72a`) records 34 actual local expert blob hashes and confirms byte equality to their GGUF gate/up/down slices; this is local observation, not authenticated publisher provenance. Four local claims cover both layers and batches; they remain `RESERVED_UNKNOWN_NO_REPLAY`. No claim may be replayed. The local ledger is not a hardware lease.

A separate no-worker layer-3 prefix run with the same two synthetic inputs produced `qsa-prefix-two.f32` SHA `e558ba7c59798f24d4311dbee0c23bc6b0043be66751b0328775ac8edada4825`. An independent NumPy calculation, using observed raw projection results, checked weighted RMS normalization, partial RoPE, FP16 KV conversion, two-cell causal softmax and gated attention. At position 1 the maximum absolute errors were 4.77e-7 for query, 1.20e-7 for key and 1.46e-8 for attention; position 0 attention error was 1.20e-8. This standalone prefix was not captured from the live Segment, and its inputs to the oracle are observed projection values: it does not establish projection, full-layer or model parity.

Both new diagnostic binaries passed Clippy with warnings denied and rustfmt; the unchanged Segment's scheduler tests in R434 passed in debug/release. No GPU or inter-PC worker ran. The QSA and GGML experts adapt the pinned MIT Strata and llama.cpp components described in R430 and `adapters/native_ggml/README.md`; donor quality is not assumed.
