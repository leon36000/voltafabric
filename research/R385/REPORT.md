# R385 — Strata-style unweighted native session boundary

R384 native sessions now expose a separate unweighted collector finish, preserving each token/slot row and leaving all gate coefficients to the downstream caller. This is distinct from the ordinary weighted f64 collector finish. `StrataUnweightedBatch::execute_native` reuses the existing final-kind admission and native GGML sessions, checks exact finite FP32 input reconstruction, and stages all CPU-owned outputs before writing them; externally owned rows are left untouched. An empty all-external batch does no worker execution. The caller still must bind the kind array to the actual model and final ownership plan, and coordinate external outputs and GPU waits.

A two-child local CPU test uses two distinct native-format synthetic experts and a synthetic final-kind array with an external-only expert. It checks both unweighted rows against independently requested resident results after FP16 round/decode, verifies the external row remains untouched, and rejects a short destination before dispatch. A second batch makes rank one finish and rank two overflow FP16; it returns an error, leaves the whole destination unchanged and invalidates both sessions. The durable CPU claim remains in force. All weights are synthetic and the native provider, not the whole model, is the numerical reference.

The session deliberately transmits ordinary finite FP16 results; this is lossy relative to native FP32 and has not been shown numerically equivalent to Strata's callback. No live Strata callback is attached. No real checkpoint weights, GPU, inter-PC execution, external synchronization or full generation are qualified. Donor versions and MIT licensing are recorded in R376 and R379; this commit adds integration code rather than importing another donor.
