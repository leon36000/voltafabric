# R424 — Resident SC117 shared expert CPU stage

Parent R423 `5462a63d44e4b6c5b3404e3fb2c2b8b16ccb960e`. Added `sc117_shared_stage::Stage`: a manifest-bound shared expert that loads and retains the BF16 scalar gate and the GGML gate/up/down matrices, then reuses them for repeated activations. It checks model/layer identity, source file size, fixed tensor dimensions, projection types and SHA-256 for all spans, along with source metadata before and after loading. Every calculation verifies the caller-provided run/model/layer/epoch identity, input length and finite arithmetic. This is a CPU component; its caller still has to authenticate input provenance and bind it to the reservation, plan, batch and attempt. It does not itself implement those identities or advance a model state. One immutable local manifest names layer 2 checkpoint slices; it contains no weights.

On PC1, with the observed layer-2 activation and real checkpoint, two calls to the same resident instance were exactly identical; output SHA-256 `3f828de5f505a41d8d31d2b40547952477375073eba08d524c6b912b8e9aa46a`. Its 2560 outputs exactly matched the shared output recorded by R423, and differed from that independently scalar-accumulated GGML reference by at most 4.66e-9. The CLI also verified rejection of wrong epoch, wrong width and nonfinite input, then successfully reused the same instance. A deliberately wrong checkpoint digest was refused with zero output bytes. These checks rerun shared-expert arithmetic only; no rank worker, R423 reservation or UNKNOWN was replayed.

Targeted tests `sc117_shared_stage` and `native_matrix` passed in debug and release, validating identity, unsupported type, invalid source and native matrix behavior; targeted Clippy with warnings denied and `cargo fmt --all -- --check` also passed. No GPU or inter-PC worker was used. This slice does not qualify complete generation or performance. The GGML quantizers and decoders remain shared with the donor; matching scalar arithmetic is not independent validation of quantization itself.
