A19 compressed resident artifact contract

resident-export accepts {source:{kind:checkpoint|resident,request:<existing request>},output:<new file>}. It uses the existing Rust immutable ResidentStack. No six-plane JSON weight output, dense weights or CPU inference fallback. Six exact named tensors: U8 vectors codes13,scales13,codes2,scales2; F32 matrices gscales13[E,N13/32],gscales2[E,N2/32]. Floats are serialized with to_le_bytes. Metadata vf_schema=QPN2_RESIDENT_V1 and vf_info carries model_revision,layer,rank,epoch,payload_bytes,physical_experts,resident_order,shape. Empty rank is all-zero shape. Resident limits are unchanged: each gate/up/down plane <=1,048,576 elements, <=1024 experts, <=128MiB final payload, revision nonblank <=256 UTF8 bytes.

Destination directory is owned/trusted and remains quiescent. The writer streams through the existing safetensors0.8 std serializer into an exclusively claimed sibling stage. It syncs, then links the newly generated file atomically without replacing a final regular file or broken symlink. No hardlinks to reference sources. Failure before publication produces no final file; failure after link is PUBLICATION_UNCERTAIN. Inspect the destination and receipt before deciding any retry. This is local publication, not distributed exactly-once execution or authenticity.

scripts.resident_artifact.load_stack bounds the header to8MiB and payload to128MiB before Safetensors materialization, requires exact metadata/types/tensor spans and EOF, verifies expected identity, clones owned contiguous CPU compressed tensors, and applies D04 SM70 numerical admission. The generic Rust codec/export remains CPU_COMPRESSED_EXPORT_ONLY: not every legal exported scale is admitted by the current GPU half-intermediate kernel. Reader and provider retain that restriction; no clamp, cache by tensor pointer, dense fallback or GPU correctness claim.

Returned tensor contents and dictionaries remain mutable. File content must remain quiescent during the read; fstat checks do not authenticate an adversarial file or guarantee immutability afterward. The current Linux reader uses an open regular file through /proc/self/fd; other OS environments are not qualified.

The existing H1 canary uses JSON by default. --resident-io safetensors or VF_H1_RESIDENT_IO=safetensors exercises the new path through Rust export, strict loader, existing provider and completion collector. It re-exports current source contents and compares exact CPU dtype/shape/bytes and metadata before provider use. This is a strict reference, not the eventual fast service loader; tiny canary source/plan/completion requests still contain the legacy weight JSON. Diagnostic revalidation is not a CUDA performance measurement.

H1 bundle receipts use VF_H1_RECEIPT_DIR exported by run_h1.sh; the resolved existing directory confines output even outside the immutable bundle. Paths that escape it, including symlinks, are rejected. Each execution claims a private 0700 resident directory. No operation replays a prior unknown hardware attempt.

Rust Cargo.lock includes the std serializer dependencies. third_party/A19_CRATES.json records actual crate repository/VCS/package checksum/SPDX expression and copied notices. Crates remain non-vendored. The Rust core remains unsafe-forbid; linked dependency implementations are not included in that assertion. Native ARM/Windows/GPU execution and full-model coverage remain pending.
